两个连续箭头键：短间隔（默认 0.1s）
箭头键与非箭头键切换：长间隔（默认 1.3s）
其他情况（如连续非箭头键，或序列开始第一个按键）：1 秒
C换超抽的是单独设置的
第一次运行可以全都改成推荐设置的1.5倍（或者更高）
